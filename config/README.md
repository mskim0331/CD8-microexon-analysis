# Configuration files

- `config.example.yaml` — portable MicroExonator configuration template. Replace placeholder paths before execution.
- `local_samples.example.tsv` — exact SRA FASTQ-to-analysis-label mapping used in this study, expressed with portable relative paths.
- `Paired_samples.tsv` — 24 R1/R2 biological-sample pair definitions.

The original server-path configuration and sample sheet are intentionally not part of the public-facing protocol because they contain machine-specific absolute paths.
