# Provenance

This directory records the computational environment and file provenance for the completed analysis.

- `system_and_software_versions.txt`: OS, hardware, MicroExonator, Snakemake, Python, Julia, SRA Toolkit, and Whippet versions.
- `reference_manifest.txt`: reference FASTA, Ensembl 114 GTF, and phyloP100way files used on the server.
- `microexonator_commit.txt`: pinned MicroExonator commit.
- `analysis_manifest.txt`: sample counts and major server-side output counts.
- `checksums.sha256`: archived project checksums.
- `whippet_git_head.txt`, `whippet_git_status.txt`, `whippet_modified_files.txt`: Whippet source state.
- `whippet_step6_SHA256SUMS.txt`: hashes for the Step 6 validation bundle.
- `project_file_manifest.txt`: server-side project inventory.

`server_archive_README.txt` is the README from the original server bundle and is retained only as provenance.
