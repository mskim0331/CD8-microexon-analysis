CD8 MICROEXON ANALYSIS - SERVER ARCHIVE

This archive is an internal source bundle for preparing the public,
reproducible analysis repository.

Included:
- final executable analysis scripts
- MicroExonator configuration and sample registries
- required upstream compatibility patch
- exact MicroExonator commit
- software/environment information
- reference-file manifest
- final analysis manifests
- representative output schemas
- analysis logs
- paired-end Whippet PSI results
- Ctrl-vs-activation differential results
- MicroExonator high-quality and PSI tables
- a separate audit of the previous analysis

Not included:
- raw FASTQ files
- paired-clean FASTQ files
- reference genome FASTA
- full GTF output
- Whippet index files
- BAM/SAM files
- Conda environments

The previous-analysis audit is preserved separately and is not intended
to be part of the primary final analysis protocol.
