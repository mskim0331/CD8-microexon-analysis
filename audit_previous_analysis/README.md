# Previous-analysis audit

This directory is an archive of the earlier exploratory workflow. It is not used to generate the final results in `analysis_results/`.

The audit is retained because it documents important methodological differences, including an earlier Whippet configuration in which R1 and R2 outputs were treated separately instead of as one paired-end biological sample.

The final workflow uses one paired Whippet quantification per biological sample and seven Ctrl-vs-activation comparisons with n=3 biological replicates per group.
